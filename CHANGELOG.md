# Histórico de versões

A versão segue o `__version__` do `gerar.py` (`python gerar.py --versao`); cada uma tem uma tag `vX.Y.Z` no
commit que a publicou.

## 0.1.0 — 18/10/2026

- Primeira versão pública: `gerar.py`, `conferir.py` com as duas provas,
  `reel.py`, `reel_narrado.py` (TTS opcional), `amostras.py`, temas e o
  post de exemplo.
